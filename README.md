# ReDEXPI 工业工程图纸数字化

**唤醒图纸中的工程知识，连接工业数据的下一程。**

*Engineering intelligence, grounded in evidence.*

ReDEXPI 是面向管道及仪表流程图（P&ID）的工程数字化项目，致力于将沉淀在图纸中的设备、管线、仪表与工艺关系，转化为可理解、可追溯、可复用的工程信息。

一张图纸，记录的不只是线条与符号，更是设计意图、工艺逻辑和长期积累的工程经验。ReDEXPI 希望让这些知识走出静态文档，在专业校核与标准化表达的基础上，成为连接工程设计、资产管理和智能应用的数据纽带。

## 项目愿景

- **让图纸可理解**：以工程语义连接设备、仪表和管线，让图形信息逐步成为有组织的工程知识。
- **让数据可追溯**：保留信息与来源之间的联系，为工程师提供可核查的依据。
- **让专业经验可积累**：将人工校核纳入数字化工作流，让修正和确认成为持续改善的基础。
- **让工程知识可复用**：面向标准化交换与系统对接，为设计协作、资产信息利用和后续智能应用创造条件。

## 研发方向

项目围绕图纸数字化、工程语义组织、关系校核与知识利用展开研发。当前仍处于研发与分阶段验证阶段；上述方向不构成已完成能力、生产可用性、准确率或标准认证的承诺。
